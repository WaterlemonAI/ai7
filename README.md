# AI7Lab Website

Corporate website for AI7Lab, a research-led enterprise AI product company based in Dubai.

## Products

- [Taed](https://taed.dev) — visual intelligence APIs
- [VendorEye](https://vendoreye.ae) — supplier intelligence
- [RoleField.ai](https://www.rolefield.ai) — multilingual AI workforce

## Local development

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production

```bash
pnpm build
pnpm start
```

The application is a Next.js server and reads Render's injected `PORT` automatically. No application secrets are currently required.
